EveryAlt

Free, open-source alternative text generator for every image. Just right click on any image to generate alt text that you can easily copy and paste.

Created by HDC (opens in a new tab). We also have a WordPress plugin. Learn more at EveryAlt.com (opens in a new tab).

AI model

All models read the image and write alt text the same way. Prices are each provider’s published rates as of and may change. You pay the provider directly; EveryAlt never bills you. The cost of each image is shown under Recent Generations.

API key

  1. Sign in at platform.openai.com/api-keys (opens in a new tab).
  2. Click “Create new secret key”, give it a name (e.g. “EveryAlt”), and copy the key. It is only shown once.
  3. Add a payment method or prepaid credits in your OpenAI billing settings; generation fails until your account has credit.

OpenAI does not use API data to train its models by default. See OpenAI API data usage (opens in a new tab).

  1. Sign in to Google AI Studio at aistudio.google.com/apikey (opens in a new tab).
  2. Click “Create API key”, choose or create a Google Cloud project, and copy the key.
  3. Optional: set up billing on the project to move from the free tier to the paid tier.

Gemini has a free tier, but Google may use free-tier prompts and images to improve its products. On the paid tier (billing enabled), your content is not used that way. See the Gemini API terms (opens in a new tab).

  1. Sign in or create an account at deepinfra.com/dash/api_keys (opens in a new tab).
  2. Click “New API key”, name it (e.g. “EveryAlt”), and copy the key.
  3. Add a payment method or credits in your DeepInfra billing settings. One DeepInfra key works for both DeepSeek V4.1 Flash and GLM-5.3-Flash.

Your images stay private. DeepInfra runs these models on its own infrastructure in data centers in the US and Canada, with a zero data retention policy: your images and the generated text are processed in memory and not stored, the content of requests is not logged, and your data is never used to train models.
